**报告编号：** CH-W29-2026  
**观察区间：** 2026-07-13 至 2026-07-19  
**对比基线：** 上一期报告编号：CH-W28-2026（历史报告未接入，跨期记录不可用，本期仅基于已检索品牌知识库和公开信息建立观察结果，未完成严格的前两期去重。）

## 一、本周结论
1. 本周未发现满足 A 类“本周确认新增”的公开市场事件（观察区间内有明确日期的官方公告/新闻/上架变更）。  
2. 本期识别到若干有业务价值的 B 类信号（无法确认是否首次发生于观察区间），对 Phoenix 在瑞士的渠道竞争和客户开发具有参考意义：  
   - OLEYVO 产品页显示 3.0 系列定价及“3–5 天交付 / 库存可购（示例页面显示 81 台）”，表明快速可得的城市通勤货源对我方中低价带形成压力。 [OLEYVO 产品页](https://oleyvo.ch/en/products/e-bike-3-0-dark-green) 。  
   - E‑Wheels（瑞士站）在产品与门店页持续推广 MOMAS 系列并列出 Zurich 等门店试骑点，显示该渠道在低中端线上促销与门店组合上动作频繁（需监控促销节奏与库存）。 [E‑Wheels MOMAS 列表页](https://www.ewheels.ch/de-ch/e-bike/momas-summit-trekking/) 。  
   - Batoo 宣传 Colibri V2.0 / Cargo 的产品化与门店试骑网络、补贴信息，提示货运/家庭 cargo 在瑞士继续成为可复制的中高价位机会窗口。 [Batoo Colibri V2.0](https://www.batoobike.ch/en/products/colibri-v2-0) 。  
   - AureusDrive 线上持续呈现 45 km/h（S‑Pedelec）产品线与 Power45 规格（高电池/大功率），为 45 km/h 场景（车队 / 城市快通勤）提供参考标杆。 [AureusDrive Power45](https://aureusdrive.ch/en/product/power45-high-top-tube/) 。

## 二、重点账户经营动态（E‑Wheels / LANDI / JUMBO）
- E‑Wheels / MOMAS（重点经营账户）：本周无 A 类确认变化，但公开页面显示其在瑞士站积极上架并推广 MOMAS 2026 系列、并列出苏黎世等实体店试骑点；证据表明其以线上促销 + 本地门店试骑维持销量节奏，短期对 Phoenix 同价位通勤/ SUV 产品形成竞争压力（B 类信号）。建议：关注 E‑Wheels 促销页与库存变动，若出现突发补货或长期折扣，评估我方促销或推替代 SKU 的时效性与报价策略。 [E‑Wheels MOMAS](https://www.ewheels.ch/de-ch/e-bike/momas-summit-trekking/) 。  
- LANDI / Trelago（已有合作资产）：LANDI 官网与商品页持续列示 Trelago City/Adventure 系列，商城/宣传资料显示可试骑与在售 SKU（无观察区间内的新品或下架公告）——保持常规监测（B 类，产品线活跃）。建议：继续监控 LANDI 促销册和门店试骑活动以捕捉恢复采购窗口或替换意向。 [LANDI Trelago 列表](https://www.landi.ch/shop/e-bikes_190202) 。  
- JUMBO / Coop：JUMBO 在线品类、季节性促销与目录仍在运作（7 月促销/折扣码存在于公开促销渠道），未见观察区间内突发采购政策或品类收缩公告；对 Phoenix 意义为持续的量贩/自有品牌竞争环境（B 类信号）。建议：监测 JUMBO 促销节奏与自有品牌（Leopard/Wheeler）上架变化以判断渠道价格锚点。 [JUMBO 电动车页面/促销册示例](https://www.jumbo.ch/de/velo-mobilitaet/velo/c/0801)。

## 三、A/B 客户开发机会（本期有价值的 B 类信号）
- OLEYVO — 3.0 交付与库存可得（B 类，证据强）：网页显示 3.0 系列定价 CHF1,890–1,950，且部分型号标注“Ships in 3–5 days / 81 E‑Bikes available”。商业含义：快速交付能力 + 在线库存会成为 DTC/直销竞争优势，短期内压缩我方在 CHF1.5k–2.0k 区间的市场空间。建议动作：内部核证是否为长期库存或临时促销，并评估我方对应 SKU 的交期与价格竞争力。[OLEYVO 页面](https://oleyvo.ch/en/products/e-bike-3-0-dark-green) 。  
- Batoo Bike — Colibri V2.0（B 类，证据中等）：产品页展示集成 GPS、防盗、720Wh 电池与补贴信息（不同城市），对 Phoenix 在 cargo 车细分的切入策略有参考价值。建议动作：评估货运车架/电池方案及本地补贴窗口，若客户有意向提出样车/报价，建立初始技术与价格可行性。 [Batoo Colibri V2.0](https://www.batoobike.ch/en/products/colibri-v2-0) 。  
- AureusDrive — S‑Pedelec / Power45（B 类，证据中等）：线上资料强调 45 km/h 型号与在卢塞恩组装表述，提示瑞士本土化 45 km/h 产品仍被市场接受。建议动作：继续观察 S‑Pedelec 市场补贴/登记要求变化，并确认是否有车队/商业订单窗口。 [AureusDrive Power45](https://aureusdrive.ch/en/product/power45-high-top-tube/) 。

## 四、价格 × 配置 × 品类信号（要点）
1. OLEYVO 3.0：标价 CHF1,890–1,950，页面显示“Ships in 3–5 days / 81 available”，配置采用 Bafang 250W 后驱、碳带传动，属于可立即供货的城市通勤价位（CHF1.5k–2k）。[OLEYVO](https://oleyvo.ch/en/products/e-bike-3-0-dark-green)
